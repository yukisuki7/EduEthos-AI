# 知芯课程助教：方向预览

本轮为三个独立首屏的静态视觉方案，供用户选方向；不是已接入模型的课程助教。课程：计算机组成原理。目标用户：学生，教师查看效果。共同主任务：理解 Cache 的作用，并能看见解答依据。共同内容见 content.json。

- A：工作台，三栏并列课程、解答和来源，适合稳定的日常问答。
- B：实验台，计算机存储结构成为主视觉，通过硬件关系讲知识。
- C：讲义，阅读优先、页边问答，适合老师已有教材的场景。

各方向统一 1440×900 桌面画布。本轮不实现登录、上传、生成问答或教师管理；控件为视觉预览。用户在对比工具里可以切换、并排和放大查看方向。未做手机端和动效，选定方向后实现。未接入学校资料，因此保留界面预览提示，以免误认为真实教学答案。

视觉标准：中文正文清晰，无重叠裁切，主要内容在首屏可见；三种方向的布局、字体和主视觉存在实际差异。本轮按方向探索流程自查，不派独立评分评审。用户已选定 A，后续交互 Demo 位于 ../course-demo。

交付检查：已逐张查看桌面实际截图，修正辅助文字对比度、小字号和截断内容，移除远程字体依赖；截图检查无控制台错误、横向溢出或图片加载失败。删除 A 重复的工程责任段落及 B 首屏外多余页脚。保留章节眉标用于定位课程；C 页边竖线标识批注范围，其较长正文行对应讲义阅读版式，实际截图可读。证据位于 shots/a.png、shots/b.png、shots/c.png 与 shots/sheet.png；报告 shots/report.json。

入口为 style-explorer.html，独立包含三种方向，支持离线打开。临时本地预览命令：python -m http.server 8765 --bind 127.0.0.1 --directory "<PROJECT_ROOT>\design-preview"；地址 http://127.0.0.1:8765/style-explorer.html。
