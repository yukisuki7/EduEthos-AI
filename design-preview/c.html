Cache 与主存构成存储层次中相邻的一环。理解它们的速度、容量与成本差异，就能看见计算机如何用局部性缩短等待。

01

为什么需要 Cache？

CPU 处理数据的速度通常快于主存供给数据的速度。Cache 把近期可能用到的数据和指令放在更靠近 CPU 的高速存储中，减少处理器等待。

为什么需要 Cache？它和主存有什么区别？

CPU 处理数据的速度通常快于主存供给数据的速度。Cache 把近期可能用到的数据和指令放在更靠近 CPU 的高速存储中，减少处理器等待。

简单来说，Cache 更快但容量小、单位容量成本高；主存容量更大、速度相对较慢，负责承载运行中的程序和数据。
