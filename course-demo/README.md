# 知芯 计算机组成原理课程助教

保留课程学习工作台界面，使用 HTML、CSS、JavaScript 与本地 Alpine.js；同源 Worker 服务端负责文档检索与 DeepSeek 调用，无第三方运行依赖。

## 腾讯云自托管账号版（2026-11-03）

新增 `server/index.mjs` 独立 Node 服务（已在 Node 22.22.3 验证），使用内置 SQLite。管理员创建个人账号、班级，并分配学生/教师。学生和教师的个人对话按服务端会话中的用户 ID 保存；教师统计只汇总被分配班级的学生提问，不返回学生私有资料或完整回答。管理员可管理账号与班级；没有开放注册。

自托管入口会注入隔离模式，个人数据不读写 `localStorage`；旧浏览器历史没有可信账号归属，不自动导入任何新账号。退出会撤销数据库会话，账号切换和过期会清除页面状态，跨标签页写入带账号一致性检查和版本号。所有账号数据接口均需服务端验证，旧平台身份请求头和 `LOCAL_PREVIEW` 无法绕过登录。

运行与部署见 [deploy/README.md](deploy/README.md)。`node scripts/check-account-isolation.mjs`、`node scripts/check-account-http.mjs`、`node scripts/check-account-ui.cjs` 分别检查数据库/API隔离、真实HTTP适配和前端状态。它们不等同于公网或真实浏览器验收。

下文关于共享体验账号、本机存储和 Sites 发布的说明适用于保留的原 Sites/本地 Demo 运行方式。直接运行 `scripts/serve.mjs` 不会启动上述个人账号服务。

## 运行

使用 Node.js 22.16+。在本目录运行 `node scripts/build-worker.mjs`，然后运行 `node scripts/serve.mjs`，打开 http://127.0.0.1:8766 。普通静态服务器不提供问答接口。

本地密钥可填入未跟踪的 `.env.local`（字段见 `.env.example`）。默认官方地址 `https://api.deepseek.com`、模型 `deepseek-flash`，均可从服务端环境变量调整。托管密钥通过 Sites 的 secret 配置，不写入代码、部署清单或浏览器。生产环境与本地环境分别配置；本次用户提供的密钥只存入托管 secret，未写入本地文件。

## 能力和边界

- 学生/教师仍是体验身份，不代表学校账号或真实课程权限。支持服务端验证的学生、教师共享体验账号；登录后可调用模型，无需 ChatGPT 登录。原平台登录也保留，站点公开访问范围不变。游客可以查看界面，调用已配置的模型仍需登录。
- 体验密码使用 PBKDF2-SHA256（100000 次、独立随机盐）校验，校验资料与会话签名密钥通过 Sites secret 配置。签名会话保存在 HttpOnly、Secure、SameSite=Strict Cookie 中，8 小时后需重登。修改账号配置或签名密钥会使原会话失效；退出操作删除浏览器 Cookie。登录按每个 Worker 实例限速，不是持久的全局防暴力破解系统。
- 网页请求 `POST /api/chat`，服务端对脱敏的原始课程资料做中文关键词和 BM25 检索，再将最多 6 条资料、问题与最近 4 轮上下文发送至 DeepSeek。不使用向量数据库，不把全文和密钥发给浏览器。
- 检索范围仅包括教学大纲第三部分的表2“课程教学目标、教学内容与学时分配”、思政申报书第3节“课程建设思路”和第5节“课程思政建设示范课程教学设计表”。其他章节保留在本地原始归档，不参与新问答检索。课程具体规定缺少证据时不能猜测；通用概念、机制和计算方法由模型补充讲解，不能把大纲列出的知识点当成技术原理证据。
- 普通概念题先直接解释，不复述大纲要求，也不插入无关申报书提醒。以保留资料中的主题相关思政方向为参考，自然融入1至2句、最多120字的启发。没有相关材料、联系牵强、或用户明确不要时不加；显式思政/教学请求仍可按需展开。不能把申报计划、教学设计中的预期成效或未经核实的案例数据当作已证事实。
- 服务端校验引用、来源类别和自动延伸引用范围，但不能保证模型每句话的事实/语义都正确；通用知识可能有误，思政衔接是否自然仍需实际使用评估。
- 回答正文不显示“课程资料”分区标题或“课程资料引用”条目；右侧“学习脉络 / 本次回答依据”栏已移除，桌面布局为历史栏和问答工作区。来源仍保存在回答快照中，手机的“查看本次依据”入口保留。程序校验引用存在性，不等同于保证模型每句话的语义均被来源支持。
- 未配置模型时仍提供明确标记的文档检索；接口失败保留输入并提示，不静默替换成预置答案。旧版讲义和规则匹配函数仅保留用于兼容历史与回归检查。
- 对话、反馈和已有资料保存在当前浏览器 localStorage。同一浏览器的两种身份共享记录；不同设备不会同步。保留最近 20 个对话、每个最多 40 轮，资料最多 40 份。
- 引用保存为回答当时的资料快照，之后停用资料不会破坏历史引用。
- 教师“数据总结”提供本机提问分类、关键词词云与高频问题榜，可切换时间范围和问题分类。统计按保留的学生体验提问计算，排除新记录中的教师试问；旧版无身份或无日期记录单独提示。词频指包含关键词的提问次数，分类是主题/词典规则，不是AI分析。
- 词云将当前最低到最高词频映射到 14–48px，同频同字号；全部同频时统一 30px，避免制造大小差异。
- “本期观察”提供一键导出 Word，浏览器内生成真正的 DOCX/OOXML，无外部请求。报告包括当前来源与时间范围的指标、分类、关键词次数、本期观察与统计口径；高频问题按当前分类导出完整榜单，页面只展示前 8 项。
- “演示数据”独立生成，供展示面板效果，不写入本机真实对话。当前没有全班数据汇总、真实学生人数或跨设备统计。
- 提问限 1000 字，最近 4 轮历史按长度截断，服务端请求体限 40000 字节；模型调用总超时 55 秒，单次输出上限 2200 tokens。仅在输出格式或引用编号不合格时最多重试一次，其他错误直接提示。每个 Worker 实例按身份每分钟最多 6 次问答请求，同时最多 3 次，每次最多调用模型 2 次。这不是跨实例的硬费用预算；提供商余额及用量需由维护者管理。
- 尚无学校账号与课程授权、班级数据库、跨设备同步或真实学生教学效果评测。本地预览绑定回环地址，允许本机模型验证；这一便利不用于托管环境。

## 资料更新与构建

原始归档在项目上级 `knowledge-base`，不随站点发布。更新原始资料后，在项目根运行 `node knowledge-base/runtime/prepare.mjs` 和检索检查，再在本目录运行 `node scripts/sync-knowledge.mjs`。部署源保留脱敏的 `worker/documents.json` 与检索代码，因此独立源码检出也可构建。

`node scripts/build-worker.mjs` 生成 `dist/server/index.js` 与部署元数据，并将必要网页资产嵌入 Worker。只有显式白名单路由会被响应，原件、本地环境文件及服务端源码不作为静态文件提供。保留同一 Sites project id，按 Worker 方式发布。

## 检查

`node scripts/check-worker.mjs` 检查真实 API 请求合同、登录边界、引用范围、限流、超时、上游失败与独立构建；使用受控服务桩，不代表真实模型通过。`node ../knowledge-base/runtime/check-retrieval.mjs` 检查检索。`node check-state.cjs` 检查前端 API、失败恢复、历史和统计；其他 check 脚本检查旧预置内容、统计和报告。真实模型和浏览器验证另记于 QA.md。

`node scripts/check-demo-auth.mjs` 检查体验账号密码、跨站请求、Cookie、过期/篡改/轮换失效、问答接口与限流；使用随机测试配置和模型桩，不会读取真实密码或调用付费模型。`node scripts/check-demo-ui.cjs` 检查登录、退出、会话恢复与失败状态。体验账号不提供独立账户数据空间；同一浏览器切换体验账号仍能查看本机历史。正式学校账号、班级数据隔离和教师授权仍需另行建设。

`node scripts/check-answer-policy.mjs` 检查三类 Cache 问题的通用回答合同、通用/课程引用边界、课程规定缺证据、无检索命中的原理题、离题及追问拦截、教学建议开关。它使用固定模型响应，不代表真实模型回答质量评测。`node scripts/check-answer-ui.cjs` 检查分区展示的数据合同、旧历史兼容、复制来源标记和本地持久化。

`node scripts/check-auto-teaching.mjs` 检查默认自动思政的文档主题候选、用户关闭、空/错误/过长引用副段丢弃、无资料和错主题时省略、以及短追问的主题继承。此项同样使用模型桩；自动候选采用保守的技术主题词表和原文明示的融入点，未识别的主题宁可不加。
